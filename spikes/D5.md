### Eligibility notes (Windows Artifact Signing)

From Microsoft Learn code-signing options (2026-11-13):

- Organizations: USA, Canada, EU, UK.
- Individuals: USA and Canada only.
- If the publisher is an individual outside US/CA, use a traditional OV certificate instead.

### SmartScreen (2024+)

EV no longer grants immediate SmartScreen reputation. OV and Artifact Signing both build reputation over download volume. Paying EV solely for SmartScreen is not justified per Microsoft Learn.

## Sandbox / helper limits

| Channel | Helper / elevation | Documented limit |
|---|---|---|
| Windows MSI/NSIS | Host-installed `hertzline-helper` (D2 short-lived `runas`) | Full allow-list available after install |
| Windows MSIX / Store | Possible sandbox / capability limits | Spike later at HZ-049; may mark some elevate ops not-possible |
| Linux Flatpak | Sandbox cannot freely talk to host polkit | Prefer host helper install **or** label privileged actions not-possible inside Flatpak |
| Linux AppImage / deb / rpm | Host binary + polkit policy | Full D2 path |
| macOS DMG | `SMAppService` helper (D2) | Register on first privileged need; unregister on uninstall |

Never silently skip signing. CI/release scripts must fail closed if signing credentials are missing for a public release job (implementation in HZ-049--HZ-051).
